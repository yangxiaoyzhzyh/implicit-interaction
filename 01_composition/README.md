# 01_composition — 组分数外推

训练用 $K\le\text{train\_max}$ 的混合物，测试 $K>\text{train\_max}$。
本轴**不早停**：留出验证集会占用一个组分数档位，且训练/测试之间只有组分数之差，
不存在需要早停抑制的分布外泛化。

> 下文所说的「本轴」一律指**组分数外推**；另两条轴是 `02_unseen_molecules`
> （新分子外推）与 `03_target_value`（极值外推）。

**本轴任务集（9 个）**：`drug`、`spe`、`iltk`、`ilteta`、`nist`、`miscible`、
`miscible_hvap`、`miscible_density`、`mon`。

**`logv` 不在本轴的任务集里**：它的组分数最大只有 2（纯组分 2,910 + 二元 31,464），
而组分数外推要求「训练 $K\le2$、测试 $K>2$」，因此测试集为空，这条轴对它无从评估。
它在另外两条轴上均可用——新分子外推（`02_unseen_molecules`，8,859 / 9,461）与
极值外推（`03_target_value`）。三个 `miscible*` 任务则相反，只在本轴可用
（测试侧 26,481 条），新分子外推算不出可信划分。

## 脚本

脚本不放在本目录，统一在 `../scripts/`，四条路线各一个：

| 脚本 | 建模 | 本轴用法 |
|---|---|---|
| `../scripts/vim.py` | v(im)：一阶聚合 + 塑形编码器 | `--split-file ../splits/<task>_composition.npz --no-early-stop` |
| `../scripts/vex.py` | v(ex)：跨组分注意力 | 同上（`--model vex` 由脚本固定） |
| `../scripts/additive.py` | 线性可加基线（每组分一个系数，**ridge α=1e-2**，无 seed） | `--task <task> --split-file ...` |
| `../scripts/frozen.py` | 冻结编码器臂（RDKit 2D 217 维） | `--task <task> --split-file ...` |

四个臂读同一份 `splits/<task>_composition.npz`，因此比较是严格可控的。
`frozen.py` 回答“增益来自表示还是来自聚合形式”，`additive.py` 提供可加性参照线。

## 加性基线为什么用 ridge（2026-10-29 改）

摩尔分数恒有 $\sum_i w_i=1$，所以组分列与截距**本来就完全共线**；当数据里出现一个占
0.9–0.999 的溶剂、其余是 $10^{-3}$ 量级的痕量组分时，普通最小二乘返回的最小范数解会给
痕量组分分配巨大且相互抵消的系数：样本内正常，样本外发散（R² 掉到 $-10^{4}$ 量级）。

改用 ridge（α=10⁻²，作用在标准化目标上）后，九个任务里**只有 IlT 两个变化**，其余七个
变动 ≤0.013：

| 任务 | 无正则 | ridge | 变化 |
|---|---:|---:|---:|
| IlT κ | −0.133 | **+0.737** | **+0.870** |
| IlT η | 0.007 | **+0.818** | **+0.811** |
| MON | 0.905 | 0.918 | +0.013 |
| SPE κ | 0.627 | 0.618 | −0.008 |
| ΔHmix | 0.760 | 0.755 | −0.005 |
| drug lnS | 0.577 | 0.579 | +0.003 |
| density / ΔHvap / NIST η | — | — | 0.000 |

对照表：`runs/additive_ridge_vs_plain.csv`；`summary.csv` 的 additive 行已换成 ridge 值
（`source` 列标注 `ridge 1e-2`）。要复现旧口径：`--plain`。

**含义**：IlT κ 的“加性基线为负”是数值病态，不是“不可加”。用 ridge 后该任务的一阶信号
很强（0.737），v(im) 的 0.732 与它**持平**而非领先 0.87。
