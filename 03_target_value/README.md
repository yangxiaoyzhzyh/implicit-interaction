# 03_target_value — 极值外推

测试集的分子、温度、组分数**全部来自训练分布**，只有目标值落在标定区间之外。
训练取目标值的四分位带，测试取两端各 10%，中间 30% 丢弃以留出空隙。

> 下文所说的「本轴」一律指**极值外推**；另两条轴是 `01_composition`（组分数外推）
> 与 `02_unseen_molecules`（新分子外推）。

## 脚本

脚本不在本目录，统一在 `../scripts/`：

**本轴任务集：全部 10 个**（三条轴里唯一全覆盖的）。每个任务的尾部样本数都在 68 条
以上；`mon` 最少（低端 68 / 高端 69），引用时应注明方差偏大。

| 脚本 | 建模 | 本轴用法 |
|---|---|---|
| `../scripts/vim.py` | v(im) | `--split-file ../splits/<task>_target.npz`（早停默认开启） |
| `../scripts/vex.py` | v(ex) | 同上（`--model vex` 由脚本固定） |
| `../scripts/additive.py` | 线性可加基线 | `--task <task> --split-file ...` |
| `../scripts/frozen.py` | 冻结编码器臂 | `--task <task> --split-file ...` |

分位带宽在 `make_splits.py --split target` 里给定：默认 `--y-train 0.25 0.75`、
`--y-test 0.10 0.90`，即四分位带训练、两端各 10% 测试、中间 30% 丢弃。
本轴允许早停，因为训练带内部可以安全留出验证集（引擎从训练侧留出 1/8，最多 600 条），
测试端的极端目标值不会因此泄漏。

## 数据

`runs/` 内是 10 任务 × 2 路线、每项 3 seed（20 个文件、60 行），`summary.csv` 归一为 20 行。
逐 seed 的原始输出就在 `runs/*_target.csv` 里（每行含 `seed`、`n_train`、`n_test`），无额外的拼接副本。

本轴划分由 `common/engine.py` 现场切分（`--split-by y --y-train 0.25 0.75 --y-test 0.10 0.90`），
不经过 `splits/*.npz`；`run_carved.py` 只提供 `carved` 与 `k` 两种取值，生成本轴须用引擎那条路径。

| 核对项 | 结果 |
|---|---|
| 划分规则 | 取 y 的 10/25/75/90 分位，训练 [q25, q75]，测试 <q10 或 >q90 |
| 复现 | 用上述命令重跑，MON 得 0.7594，归档 0.7596（差 0.0002） |
| 超参 | batch 128、200 epoch、knee 早停、seeds 42/43/44 |
| 数据 | 取自 CheMixHub，归档不附数据副本 |

## 这个轴的作用

它不是用来区分两条路线的，而是用来**排除一种解释**：如果 v(im) 的优势只是因为
“测试集离训练集更远”，那么在只有目标值外推、结构全部在分布内的划分上，它也该赢。
结论：v(im) 胜 4 项、平 4 项（差 ≤0.01）、负 2 项；两条路线在本轴上的差距远小于组分数轴。
